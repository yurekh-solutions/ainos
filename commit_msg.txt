GST scraper keep-alive: self-sustaining 3-layer protection

1. Server-side /api/keep-scraper-alive endpoint pings scraper from AINOS server
2. KeepScraperAlive client component pings every 4 min while user is on dashboard
3. Combined with existing GitHub Actions 5-min cron and server-side retry

Result: scraper stays awake as long as anyone uses AINOS — no more 502s.
