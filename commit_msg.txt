fix: replace all Framer Motion with plain HTML on sign-in page

Root cause: Framer Motion initial={{ opacity: 0 }} animations were not
firing on the deployed site, leaving the entire sign-in page invisible.
The Google button existed in the DOM but had opacity: 0, making it
impossible to click.

Fix: Replaced all motion.* elements with regular HTML elements.
The page now renders immediately with full visibility - no animation
dependency. CSS hover effects preserved via Tailwind classes.
