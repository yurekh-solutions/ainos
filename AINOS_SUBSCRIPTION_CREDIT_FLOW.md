# AINOS — Complete Subscription & Credit System

## Simple Explanation (Hindi)

AINOS mein **2 alag cheezein** hain jo milkar kaam karti hain:

1. **Subscription** = Darwaza (kaunse rooms mein ja sakte ho)
2. **Credits** = Petrol (har AI tool chalane ka fuel)

---

## Part 1: Subscription (Darwaza)

Subscription decide karta hai ki **kaunse apps/tools access** kar sakte ho.

### Plans Available

| Plan | Price | Kya Milta Hai |
|------|-------|---------------|
| **Trial** | ₹0 | Sab kuch 14 din, 200 credits |
| **Individual App** | ₹799/mo | 1 app (CRM ya Books ya HR etc.) |
| **AI Studio** | ₹1,499/mo | Sirf AI tools, 2,000 credits |
| **AINOS One** | ₹3,999/mo | Sab kuch unlocked, 5,000 credits |

## Part 2: Credit System (Petrol)

Credits tab kat-te hain jab koi **AI tool** use hota hai.

### Har Tool Ka Credit Cost

**Non-AI Tools = 0 Credits (subscription se hi chal jaate hain):**

| Tool | Credit Cost | Kyun |
|------|-------------|------|
| Invoice Generator | 0 | Manual operation, no AI |
| CRM (Contacts/Leads) | 0 | Database operations |
| Inventory Management | 0 | Stock tracking |
| HR & Payroll | 0 | Calculation, no AI |
| Email Marketing (send) | 0 | Template-based |
| Helpdesk | 0 | Ticket management |
| Products/Stock | 0 | CRUD operations |

**AI Tools = Per-Run Credit Cost (har baar chalane pe katenge):**

| Tool | Slug | Credit Cost | Example |
|------|------|-------------|---------|
| Logo Generator | `logo` | 5 | 1 logo = 5 credits |
| Brand Kit | `brandkit` | 10 | 1 brand kit = 10 credits |
| Social Media Pack | `social` | 8 | 1 pack = 8 credits |
| Content Writer | `content` | 3 | 1 article = 3 credits |
| SEO Audit | `seo` | 5 | 1 audit = 5 credits |
| Email Copy | `email` | 3 | 1 email = 3 credits |
| PR Outreach | `pr` | 5 | 1 PR kit = 5 credits |
| Launch Kit | `launch` | 15 | 1 launch = 15 credits |
| Poster Design | `poster` | 5 | 1 poster = 5 credits |
| QR Code | `qr` | 1 | 1 QR = 1 credit |
| Pitch Deck | `pitchdeck` | 10 | 1 deck = 10 credits |
| Product Listing | `listing` | 5 | 1 listing = 5 credits |
| Business Plan | `bizplan` | 15 | 1 plan = 15 credits |
| Legal Docs | `legal` | 8 | 1 doc = 8 credits |
| AI Chatbot | `chatbot` | 2 | 1 session = 2 credits |
| Auto Blog (per post) | `autoBlog` | 5 | 1 blog = 5 credits |
| Website Builder | `websiteGen` | 25 | 1 site = 25 credits |

## Part 3: Complete Flow (Step by Step)

### Scenario 1: Naya User Signup → Trial Starts

```
USER ACTION:
  User registers on AINOS (email/password ya Google)

DATABASE CHANGES:
  1. Company table:
     INSERT { id: "comp_new", name: "My Business", 
              subscriptionStatus: "trial",
              autoBlog: false, invoiceGen: false, ... (sab false) }

  2. User table:
     INSERT { id: "user_new", email: "user@gmail.com", 
              companyId: "comp_new", role: "user" }

  3. CreditBalance table:
     INSERT { companyId: "comp_new", balance: 200 }
     ↑ 200 welcome credits (trial)

  4. Subscription table:
     INSERT { companyId: "comp_new", userId: "user_new",
              plan: "one", status: "trialing",
              trialEndsAt: 2026-10-21 (14 days baad) }

  5. Company table (trial = sab unlocked):
     UPDATE { autoBlog: true, invoiceGen: true, crmAccess: true, 
              inventoryMgmt: true, hrPayroll: true, emailMarketing: true,
              aiAssistant: true, websiteGen: true }
```

### Scenario 2: User Invoice Banata Hai (Non-AI Tool = 0 Credits)

```
USER ACTION:
  Dashboard → Finance → Create Invoice → Fill details → Save

API CALL:
  POST /api/invoices { customerName: "Rahul", items: [...], total: 5000 }

CHECKS:
  1. tool-guard.ts → requireToolAccess('invoiceGen')
     → Company.invoiceGen = true? → YES → proceed
     → Company.invoiceGen = false? → 402 "Invoice subscription required"

  2. Credit check? → NO (invoiceGen ka creditCost = 0)

DATABASE CHANGES:
  1. Invoice table:
     INSERT { invoiceNumber: "INV-001", customerId: "...", 
              total: 5000, companyId: "comp_new", status: "draft" }

  2. CreditBalance: NO CHANGE (0 credits)
  3. CreditTransaction: NO ENTRY
  4. ToolRun: NO ENTRY (non-AI tool)
```

### Scenario 3: User Logo Generate Karta Hai (AI Tool = 5 Credits)

```
USER ACTION:
  Dashboard → Services → Pick "Logo Generator" → Enter business name → Generate

API CALL:
  POST /api/ai-tools { tool: "logo", inputs: { businessName: "Sharma Ji" } }

CHECKS (in order):
  1. Subscription check (billing.ts → checkQuota):
     → User ka subscription active/trialing hai? → YES
     → AI Studio app access hai? → YES (trial = all apps)
     → Monthly tool run limit cross nahi hua? → YES (under limit)

  2. Credit check (credits.ts → getCreditBalance):
     → Current balance = 200
     → Tool table se creditCost = 5 (logo ke liye)
     → 200 >= 5? → YES → proceed
     → 200 >= 5? → NO → 402 "Insufficient credits. Buy credit pack."

EXECUTION:
  3. ai-tools.ts → runLogo(inputs)
     → Pollinations.ai se image generate hota hai
     → Output: { logo: "https://image.pollinations.ai/...", variations: [...] }

DATABASE CHANGES:
  1. ToolRun table:
     INSERT { tool: "logo", toolName: "logo",
              serviceName: "Logo Generator",
              businessName: "Sharma Ji",
              inputs: { businessName: "Sharma Ji" },
              output: { logo: "https://...", ... },
              userId: "user_new", companyId: "comp_new",
              aiUsed: true, status: "completed" }

  2. CreditBalance table:
     UPDATE { balance: 200 - 5 = 195 }
     WHERE companyId = "comp_new"

  3. CreditTransaction table:
     INSERT { companyId: "comp_new",
              type: "debit",
              amount: -5,
              balanceAfter: 195,
              description: "Logo Generator" }
```

### Scenario 4: Credits Khatam → User Pack Kharidta Hai

```
USER ACTION:
  Balance = 3 credits (logo nahi banega, 5 chahiye)
  Dashboard → Billing → Credits → Buy "Pro Pack" (1000 credits, ₹499)

STEP 1: Create Razorpay Order
  API CALL:
    POST /api/billing/checkout { creditPackId: 1000 }

  DATABASE:
    Razorpay API → createOrder(499 * 100 paise, receipt: "credits_comp_new_123456")
    Response: { orderId: "order_xyz", amount: 499, credits: 1000 }

STEP 2: User Pays on Razorpay
  → User Razorpay popup pe card/UPI se ₹499 pay karta hai
  → Razorpay payment successful

STEP 3: Razorpay Webhook (automatic)
  API CALL:
    POST /api/webhooks/razorpay
    Body: { event: "payment.captured", payload: { payment: { receipt: "credits_comp_new_123456", amount: 49900 } } }

  CHECKS:
    → verifyWebhookSignature(body, signature) → valid?
    → receipt se companyId extract: "comp_new"
    → amount se pack find: 49900 paise = ₹499 → Pro Pack (1000 credits)

  DATABASE CHANGES:
    1. CreditBalance table:
       UPDATE { balance: 3 + 1000 = 1003 }
       WHERE companyId = "comp_new"

    2. CreditTransaction table:
       INSERT { companyId: "comp_new",
                type: "credit",
                amount: +1000,
                balanceAfter: 1003,
                description: "Payment: pay_razorpay_123" }
```

### Scenario 5: Subscription Expire → Tools Locked

```
TIME PASSES:
  Trial 14 days baad expire hota hai

AUTOMATIC CHECK (middleware.ts):
  → Subscription.status = "trialing"
  → trialEndsAt = 2026-10-21 (past)
  → NOW = 2026-10-22

DATABASE CHANGES:
  1. Company table:
     UPDATE { subscriptionStatus: "inactive",
              autoBlog: false, invoiceGen: false, crmAccess: false,
              inventoryMgmt: false, hrPayroll: false, emailMarketing: false,
              aiAssistant: false, websiteGen: false }

USER EXPERIENCE:
  → Dashboard mein sab tools "locked" icon dikhayenge
  → Click karne pe: "Subscribe to unlock" popup
  → /billing page pe redirect hoga
  → Credits balance phir bhi bach sakte hain (expire nahi hote)
```

## Part 7: Key Points Summary

1. **Subscription = Access Control**
   - Kaunse tools/apps use kar sakte ho
   - Company table pe boolean flags (true/false)
   - Subscription table pe record (plan, status, dates)

2. **Credits = Consumption Metering**
   - Har AI tool run pe credits kat-te hain
   - CreditBalance table pe current balance
   - CreditTransaction table pe history (bank statement jaisa)

3. **Non-AI Tools = 0 Credits**
   - Invoice, CRM, Inventory, HR → subscription se hi chal jaate hain
   - Koi credit deduction nahi

4. **AI Tools = Per-Run Credit Cost**
   - Logo = 5, Blog = 5, Website = 25, etc.
   - Tool table pe creditCost field
   - Har run pe deductCredits() call hota hai

5. **Credit Packs = Topup**
   - Jab monthly credits khatam ho jaayein
   - Razorpay se kharido → webhook se addCredits() hota hai

6. **Subscription ID Format**
   - `sub_` + UUID (e.g., `sub_7f3a2b1c-9d8e-4f7a-b6c5-d4e3f2a1b0c9`)
   - Prisma `@default(uuid())` se auto-generate hota hai

7. **Credits Never Expire**
   - Unused credits carry forward to next month
   - Monthly grant add hota hai, purane balance nahi hat-ta
