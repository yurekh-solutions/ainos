5 — Multi-Tenant Isolation Model

🔒 companyId Isolation — Every Query, Every Time

Every business model carries a companyId field. Every authenticated API route reads the session user's companyId and filters its Prisma queries by it — so Company A's data never leaks into Company B's dashboard.

┌─────────────┐ ┌──────────────┐ ┌────────────────┐ │ User Login │ ──→ │ Session + │ ──→ │ Prisma Query │ │ (NextAuth) │ │ companyId │ │ WHERE companyId│ └─────────────┘ └──────────────┘ └────────────────┘
